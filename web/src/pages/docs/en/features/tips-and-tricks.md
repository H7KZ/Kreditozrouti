# Tips & tricks

- **Search for a free period:** Drag across an empty area in **My Timetable**, then confirm **Search courses**. The course list opens with that day and time selected.
- **Compare alternatives:** Save a timetable, duplicate it, then change a few slots. You can keep up to five named schedules in this browser.
- **Share a plan:** Use **Share** in the timetable toolbar. Anyone with the link can view the snapshot and save a copy, so share it only with people you intend to give access.
- **Take it to your calendar:** Use the calendar export dialog to review dates and events before downloading an `.ics` file or creating a subscription link.
- **Reduce clutter:** Mark passed courses as completed in the wizard or an expanded course row. Turn on **Show completed courses** when you need to find them again.
- **Check prerequisites:** Expand a course to see available prerequisite information. Linked course codes start a search; verify final requirements in InSIS.

See [Filters](/docs/en/features/filters) and [Timetable](/docs/en/features/timetable) for the full steps.
