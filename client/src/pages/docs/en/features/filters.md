# Filters

The left sidebar contains all filters. Active filters are counted in the sidebar header badge. Each filter section is
collapsible — click the section header to expand or hide it.

Filters combine: all active filters apply at once. To start fresh, use **Clear all** in the sidebar header.

## Search

Type a course name or code (e.g. `4IT101`) to find courses instantly. The search matches both the full course title and
the course code.

## Syllabus Search

Full-text search across course aims, learning outcomes, and syllabus text. Use this when you're looking for courses on a
specific topic rather than a specific course code.

## Faculties

A checkbox list of all VŠE faculties. Each faculty shows how many matching courses it has. Check one or more faculties
to limit results to those departments.

## Study Level

Filter by programme level: Bachelor's, Master's (follow-up), Doctoral, MBA, and others. Useful when browsing courses
across faculties that teach at multiple levels.

## Language of Instruction

Filter to courses taught in a specific language. Available options include Czech, English, German, Spanish, French, and
others. Combine with other filters to find, for example, English-taught electives on a specific day.

## Course Groups

Narrows results to a specific course group within your study plan: faculty-specific groups, university-wide
requirements, field-specific requirements for bachelor's or master's level, and minor specializations.

## Category

Filter by course obligation type: compulsory (oP), elective (oV), language courses (oJ1), state exams, physical
education (TV), free electives (cVB), and others.
See [Getting Started](/docs/en/getting-started#1-the-vše-credit-system) for a description of each category code.

## ECTS Credits

Filter to courses worth a specific number of ECTS credits. Useful when you need to fill a precise credit gap.

## Completion Mode

Filter by how the course is completed:

- **Exam** (zkouška) — written or oral final exam
- **Credit** (zápočet) — continuous assessment, no final exam
- **Defense** (obhajoba) — thesis or project defense

## Assessment Methods

Filter by how the course is assessed — written exam, oral exam, project, seminar paper, test, presentation, and more.
Multiple methods can be selected.

## Lecturers

Filter to courses taught by a specific lecturer. Start typing a name to narrow the list.

## Time Restriction

Include only courses that have at least one slot within a specific day and time range. You can add multiple time
windows.

The fastest way to set a time restriction is to use [Drag-to-filter](/docs/en/features/timetable#drag-to-filter)
directly on the timetable grid.

To remove a time restriction: expand the Time Restriction section and delete the entry, or click **Clear all**.

## Completed Courses

Toggle to show or hide courses you've marked as already passed. When hidden, completed courses disappear from the list
entirely — useful for keeping your view focused on what you still need.

See [Mark as completed](/docs/en/features/timetable#mark-as-completed) for how to mark courses.

## Hide Conflicting Courses

When enabled, hides courses where _all_ available time slots overlap with your current timetable. Courses that still
have at least one non-conflicting slot remain visible so you can swap to a different time.

## Fits My Timetable

Sorts the course list by how well each course fits into your current schedule and hides courses that conflict with every
available slot. Courses that fit especially well show a labelled chip:

- **Fills a gap** - the course slots into an existing gap between your classes (the best fit)
- **Same day** - the course lands on a day you already attend

Only these two positive cases show a chip, so a chip on a row reliably means the course is worth a look; neutral fits and
courses that only add a new day show no chip. This filter is disabled when your timetable is empty.
