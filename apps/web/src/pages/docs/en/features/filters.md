# Filters

Use the sidebar to narrow the course list. Filters work together; **Clear all** resets them. Each section can be collapsed, and the sidebar shows how many filters are active.

## Find courses

- **Search** matches a course name or code, such as `4IT101`.
- **Syllabus search** looks through course aims, learning outcomes, and syllabus text.
- **Faculties, study levels, languages, groups, and categories** narrow the catalog by its course attributes. Available choices depend on current results.
- **ECTS, completion mode, assessment methods, and lecturers** provide more specific choices.

## Find a time

**Time restriction** keeps courses with a slot in a selected day and time window. Add more than one window if needed. You can also [drag across the timetable grid](/docs/en/features/timetable#drag-to-filter) to create a window.

**Hide conflicting courses** removes courses whose available slots all overlap your selected timetable. A course stays visible if at least one slot can fit.

**Fits my timetable** ranks courses against your current schedule and excludes courses with no fitting slot. A chip highlights a course that fills a gap or meets on a day when you already have class. This option is available after you add a timetable slot.

## Completed courses

Use **Show completed courses** to include courses marked as passed. You can mark a course in the setup wizard or its expanded row. See [Timetable](/docs/en/features/timetable#mark-as-completed).
