# Optimizer

The **Optimizer** tab proposes timetables for courses you choose. It helps compare combinations of teaching slots when arranging them by hand is difficult.

## Generate options

1. Search by course name or code and add courses to the basket.
2. Optionally set an ECTS range, preferred days, unavailable time windows, and a limit on consecutive class time.
3. Select **Generate timetables**. The constraints are saved in this browser.

The results show ranked schedules that fit all basket courses. If none fits, the app also shows alternatives that omit one course. A result card has a small timetable, a quality tier, and reasons such as gaps or classes outside preferred days.

Open a card to inspect the full week and score details. New slots are highlighted so you can compare them with your current timetable. **Use this timetable** replaces your current selection with that candidate.

## Find another course

**What else fits?** searches study-plan courses that could be added to the basket. Select a category, optionally a group, then **Find fits**. Preview a suggestion before applying it. A course with no conflict-free combination is marked accordingly.

The optimizer is a planning aid. Check current slots and availability in InSIS before enrolling.
