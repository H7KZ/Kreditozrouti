# Feature overview

Use this page when a code change affects student-facing behavior. The published guide in [`web/src/pages/docs/`](../../web/src/pages/docs/) provides the detailed English and Czech instructions.

| Area | Current behavior | Published guide |
| --- | --- | --- |
| Setup | Faculty, entry year, study plans, and optional completed courses; selections persist in the browser | [Getting started](../../web/src/pages/docs/en/getting-started.md) |
| Course search | Search, syllabus search, attribute filters, time windows, timetable fit, and completed-course visibility | [Filters](../../web/src/pages/docs/en/features/filters.md) |
| Timetable | Select teaching slots, detect overlaps and short known-campus transfers, save up to five schedules | [Timetable](../../web/src/pages/docs/en/features/timetable.md) |
| Optimizer | Rank schedule candidates from a course basket and constraints; suggest other fitting courses | [Optimizer](../../web/src/pages/docs/en/features/optimizer.md) |
| Course details | Syllabus, prerequisites, lecturer and room details, and on-demand InSIS refresh | [Timetable](../../web/src/pages/docs/en/features/timetable.md) |
| Sharing and export | Read-only share links, calendar export or subscription, and timetable image export | [Timetable](../../web/src/pages/docs/en/features/timetable.md) |
| Language and theme | Czech or English interface; light, dark, or system theme | [FAQ](../../web/src/pages/docs/en/faq.md) |

Kreditožrouti is a planning tool. Students must verify course availability and enroll in InSIS. Keep the English and Czech published pages aligned when these flows change.
